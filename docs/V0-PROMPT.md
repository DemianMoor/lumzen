## V0 DESIGN PROMPT — PASTE THIS INTO v0.dev

---

Design a full dark-mode subscriber dashboard for a spiritual manifestation platform called **LumZen** with the tagline *"Where Light Meets Stillness"*. The platform lives at lumzen.co and gives subscribers unlimited access to 5 product categories: Spiritual Guides, Sacred Audiobooks, Affirmation Practice, Meditation & Sound Healing, and Celestial Tools (Tarot + Natal Charts).

---

## BRAND & VISUAL IDENTITY

**Brand concept:** LumZen = *Lum* (light, luminosity) + *Zen* (stillness, presence). The visual identity must embody the tension between these two forces — dark, vast, still space interrupted by soft luminous light. Think: the moment just before a star ignites. The silence between breaths.

**Core aesthetic:** Dark cosmic luxury. Not aggressive or neon — serene and celestial. Like floating in deep space, warm and weightless.

**Color system:**
```
--bg-base: #06060f           /* Near-black with deep blue undertone */
--bg-surface-1: #0c0c1e      /* Card layer 1 */
--bg-surface-2: #12122a      /* Card layer 2 */
--bg-surface-3: #1a1a35      /* Elevated card */
--accent-lum: #c4a35a        /* LumZen gold — warm, not gaudy */
--accent-zen: #6b9fd4        /* LumZen blue — calm cosmic */
--accent-glow: #8b6fc9       /* Soft violet glow for active states */
--accent-mist: #4db8a8       /* Teal — used for sound/frequency elements */
--text-primary: #f0eff8      /* Near-white with slight lavender */
--text-secondary: #8f8daa    /* Muted mid-tone */
--text-muted: #4a4866        /* Faintest visible text */
--border-subtle: rgba(196,163,90,0.15)   /* Gold border, nearly invisible */
--border-active: rgba(196,163,90,0.5)    /* Gold border, hovered/active */
```

**Typography:**
- Display/hero headings: **"Cormorant Garamond"** — regal, mystical, high-contrast serif. Use for all H1 and H2.
- Section labels & nav: **"Cinzel"** — classical Roman caps, use at 11–13px, letter-spacing 0.2em, uppercase only.
- Body text: **"Jost"** — clean, warm, geometric. Readable at 14–16px.
- Data/numbers (degrees, Hz values, times): **"JetBrains Mono"** — used sparingly for technical spiritual data.

---

## ANIMATED BACKGROUND SYSTEM

Create a layered cosmic background fixed behind all content:

**1. Star field (3 layers):**
- Layer A: 200 tiny dots (1px), opacity 0.3, random positions, twinkling animation 3–7s
- Layer B: 80 small dots (1.5px), opacity 0.5, random positions, twinkling animation 2–5s
- Layer C: 25 medium dots (2–3px), opacity 0.7, with a subtle white glow shadow, twinkling 4–8s
- Stars rendered as absolute-positioned divs with randomized top/left and animation-delay via inline style

**2. Nebula gradients (behind everything):**
- Gradient 1: radial, `rgba(107,79,160,0.18)` at center → transparent, positioned top-left at -20%, -10%, size 70vw
- Gradient 2: radial, `rgba(77,184,168,0.10)` at center → transparent, positioned bottom-right at 110%, 110%, size 60vw
- Both animate with a slow 25s float cycle: `transform: translate(-15px, -20px) → translate(15px, 20px)` ease-in-out infinite alternate

**3. Lum-Glow orb:**
- A single 400px × 400px circle, `background: radial-gradient(circle, rgba(196,163,90,0.08) 0%, transparent 70%)`
- Blurred: `filter: blur(60px)`
- Orbits slowly behind the hero section with a 30s CSS animation

## MICRO-INTERACTIONS & ANIMATION

- **Page load:** Staggered fade-up of sections — each section 80ms delay after previous, opacity 0→1, translateY 20px→0, duration 600ms
- **Star twinkling:** CSS `@keyframes twinkle` — `opacity: 0.3 → 0.9 → 0.3`, `scale: 1 → 1.2 → 1`, duration randomized 2–7s
- **Nebula float:** `@keyframes nebulaDrift` — `transform: translate(-15px,-20px)` → `translate(15px,20px)`, 25s ease-in-out infinite alternate
- **Gold shimmer on buttons:** Pseudo-element `::after` that sweeps a `rgba(255,255,255,0.15)` highlight from left to right on hover, 600ms
- **Card hover lift:** `transform: translateY(-6px)` + gold shadow, 200ms ease
- **Group card dim:** Sibling cards get `opacity: 0.6 filter: brightness(0.8)` when a card in the same row is hovered
- **Audio player pulse:** The avatar ring in the header pulses softly (opacity 0.4 → 0.8, scale 1 → 1.05) when audio is playing
- **Tarot card reveal:** On button click, card flips with CSS `rotateY(180deg)` transform, 800ms ease
